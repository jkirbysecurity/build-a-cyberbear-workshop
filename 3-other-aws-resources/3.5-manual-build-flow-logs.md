# 3.5 - Manually Build VPC Flow Logs

### Objectives

The objective of this lesson is to walk through manually building and configuring **VPC Flow Logs** in the console for learning how they are built and comparison to using code.


## Challenges

### Challenge 1: Manually Configure A VPC Flow Log

1. From the **Main Home Page**, select **VPC**

    ![VPC - Search](/3-other-aws-resources/images/17-vpc-search.png)

    ---

2. Select your VPC, select the **Flow log** tab, and select **Create flow log**

    ![Flow Log - Create](/3-other-aws-resources/images/18-flow-log-create.png)

    ---

3. Name your flow log `manual-range-flow-log`

    - **Notice** the flow log is being attached to the `manual-range-vpc`
    - Also **notice** the **Filter** is set to **All** be default

        ![Flow Log - Name](/3-other-aws-resources/images/19-flow-log-name.png)

        ---

4. Set the destination for where you want your logs to go

    - Set destination to **Send to an Amazon S3 bucket**
    - Paste the previously copied **S3 bucket ARN** to send logs to your bucket of choice
        - If you do not have it handy, go back to S3 in another tab --> select your bucket --> go to **Properties** tab --> copy the **ARN**
    - Notice the **Log record format** is **AWS default format**, keep the default

        ![Flow Log - Destination](/3-other-aws-resources/images/20-flow-log-destination.png)

        ---

5. Scroll down the rest of the way.  Keep the defaults.  Select **Create flow log**.

    ![Flow Low - Create Flow Log](/3-other-aws-resources/images/21-flow-log-create-log.png)

    ---

### Challenge 2: Review Flow Log

1. After creating the flow log, you will be dropped into the flow log details

    - Notice the **Name, Destination Type, Destination Name, Traffic Type, Max Aggregation Interval,** and **Log Format**

    ![Flow Log - Details](/3-other-aws-resources/images/22-flow-log-review.png)

    ---

2. Another level of verification

    - Select **Your VPCs** in the left column
    - Select your VPC `manual-range-vpc`
    - Select **Flow logs** tab
    - See flow logs **Name, Traffic type,** and **Destination type**

        ![Flow Logs - VPC Verification](/3-other-aws-resources/images/23-flow-log-vpc.png)

        ---

3. Verify your S3 bucket is getting the logs

    - Go back to your bucket and see the **Objects** tab
    - You should now see an **AWSLogs/** folder that was not there before
    - *(Optional) If you left your `manual-web-server` up and running, you could connect/ssh into the instance to create traffic and drill deeper into the **AWSLogs/** folder to see and review the logs.*

        ![Flow Logs - Bucket Verification](/3-other-aws-resources/images/24-flow-log-bucket-verify.png)

        ---

**-- End Of Exercise --**
