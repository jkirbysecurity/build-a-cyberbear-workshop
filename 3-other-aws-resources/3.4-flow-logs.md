# 3.4 - VPC Flow Logs

### Objectives

The objectives of this lesson are to get familiar with **VPC Flow Logs**.

### What are VPC Flow Logs?

**[VPC Flow Logs](https://docs.aws.amazon.com/vpc/latest/userguide/flow-logs.html)** are the core logging service used to capture information about the IP traffic inside of your VPC. 

- Flow logs can be:
    - Configured to capture **accepted traffic**, **rejected traffic**, or **all traffic**
    - Attached to a VPC, a Subnet, or directly to a specific network interface

- Flow logs can capture a lot of useful network traffic data which can help with:
    - Diagnosing overly restrictive security group rules
    - Monitoring the traffic that is reaching your instance
    - Determining the direction of the traffic to and from the network interfaces
    - View all [available fields](https://docs.aws.amazon.com/vpc/latest/userguide/flow-log-records.html#flow-logs-fields) and respective descriptions for more details

- Flow log data can be published to **Amazon CloudWatch Logs**, **Amazon S3**, or **Amazon Data Firehose**

- Some important [limitations](https://docs.aws.amazon.com/vpc/latest/userguide/flow-logs-limitations.html) --> they **do not** inspect traffic
    - They do not have visibility into what the packet is carrying/delivering.  You can, however, setup traffic mirroring to do out-of-band inspection.
