# 3.1 - Amazon S3

### Objectives

The objectives of this lesson are to get familiar with **Amazon S3**.

### What is S3?

**[Amazon S3](https://aws.amazon.com/s3/)** is AWS's service for object storage.  Meaning you can store just about any type of data in it --> objects.  They just can not run an operating system.  

S3 stands for **Simple Storage Service**, hence "S3".  It can be used to store just about anything, 

Object storage uses a flat architecture to store data as individual units, making it more scalable and suited for unstructured data.  While you can create folders in the GUI and organize it to appear like a file system, it is not a file system.  It is really just a file naming convention to organize your objects in a flat architecture.  File system storage, on the other hand, organizes data in a hierarchical structure using files and folders.   

- S3 has high scalability, data availability, security and performance
- Use cases include --> data lakes, cloud-native applications, and mobile apps
- It has cost-effective storage classes and easy-to-use management features
    - Optimize costs, organize and analyze data, and configure fine-tuned access controls to meet specific business and compliance requirements

**Cloud-native & cost effective** -- Pairing S3 with EC2 and other compute services, allows you to offload all of your data storage to a significantly cheaper and more durable solution from your compute services.  Thus allowing your servers to just run the operating systems -- keeping them small, fast, and disposable.
