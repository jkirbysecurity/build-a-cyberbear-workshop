# 0.3 - Install Terraform

This section walks through installing **Terraform**

[Install Terraform](https://developer.hashicorp.com/terraform/install)

[Install Terraform via cli](https://developer.hashicorp.com/terraform/tutorials/aws-get-started/install-cli)


## Windows - Chocolatey

1. Open **Windows PowerShell ISE Run as administrator** and run the following commands

    - **Chocolatey** is a popular Windows package manager.  If you do not already have Chocolatey installed, run the following command to install it now.

        `Set-ExecutionPolicy Bypass -Scope Process -Force; [System.Net.ServicePointManager]::SecurityProtocol = [System.Net.ServicePointManager]::SecurityProtocol -bor 3072; iex ((New-Object System.Net.WebClient).DownloadString('https://community.chocolatey.org/install.ps1'))`

    - Once Chocolatey is installed, run the following choco commands to install **Terraform**

    `choco feature enable -n allowGlobalConfirmation`
    
    `choco install terraform -y`

2. Verify install by running `terraform help`


## MacOS - Homebrew

1. Open terminal and run the following commands

    - **Homebrew** is a popular MacOS package manager.  If you do not already have Homebrew installed, run the following command to install it now.

        `/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"`

    - Once Homebrew is installed, run the following brews to install **Terraform**
    
        `brew tap hashicorp/tap`

        `brew install hashicorp/tap/terraform`
    
        `brew upgrade hashicorp/tap/terraform`

2. Verify install by running `terraform help`
