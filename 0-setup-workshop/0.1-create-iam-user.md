# 0.1 - Create AWS IAM User

This section walks through creating an IAM User named **"devsecops"**

### Challenge 1: Log into AWS and Go TO the IAM Service

1. Log into your personal AWS account console using your root user

2. Using the search bar, search for **IAM** and select **IAM** from the **Services** drop down    
    
    ![AWS Home Page](/0-setup-workshop/images/aws-home-page.jpg)

    ---

    ![IAM Search](/0-setup-workshop/images/aws-iam-search.jpg)

    ---

3. From the **IAM Dashboard**, select **Users**.  Or from the **Identity and Access Management (IAM)** menu in the left-side navigation, under **Access Management**, select **IAM users**.
    
    ![Select IAM User](/0-setup-workshop/images/aws-iam-user.jpg)

    ---

### Challenge 2: Create User

1. Select **Create user**

    ![Create User](/0-setup-workshop/images/aws-create-user.jpg)

---

1. **Specify user details** 
    
    - Add User name **"devsecops"**
    - Check box to provide user access to the AWS Management Console
    - Create a **custom password** of your choosing
    - Select **Next**

        ![Specify user details](/0-setup-workshop/images/aws-specify-user-details.jpg)

    ---

2. **Set permissions**

    - Select **Attach policies directly**
    - Search for and select **`AdministratorAccess`**
    - Select **Next**

        ![Set permissions](/0-setup-workshop/images/aws-set-permissions.jpg)

    ---

3. **Review and create**

    - If everything looks good, select **Create user**

        ![Create user review](/0-setup-workshop/images/aws-create-user-review.jpg)

    ---

4. Copy console sign-in URL, user name, and password into your password manager of choice, and **return to users list**.


### Challenge 3: Create AWS Access Keys

1. Select the new **devsecops** user you just created.  Go to the **Security credentials** tab.  Scroll down to **Access keys** and select **Create access key**.

    ![Create access key](/0-setup-workshop/images/aws-create-access-keys.jpg)

    ---

2. Select **Command Line Interface (CLI)** for the **Use case**.  Read the **Alternatives recommended** alert, and check the **Confirmation** box to confirm you understand.

    ![Use case](/0-setup-workshop/images/aws-use-case.jpg)

    ---

3. Add a **Description tag value** -- "devsecops key" or something similar and select **Create access key**

    ![Description tag value](/0-setup-workshop/images/aws-description-tag-value.jpg)

    ---

4. Copy your new **Access key** and **Secret access key** into your password manager of choice along side your console login user you previously added, and select **Done**.

    ![Copy Access Key](/0-setup-workshop/images/aws-copy-access-key.jpg)

    ---


### Challenge 4: Install AWS CLI & Configure Profile

1. [Install the latest AWS CLI](https://docs.aws.amazon.com/cli/latest/userguide/getting-started-install.html) for your respective system

    **MacOS**
    - Open terminal and run the following commands
    
    `curl "https://awscli.amazonaws.com/AWSCLIV2.pkg" -o "AWSCLIV2.pkg"`
      
      `sudo installer -pkg ./AWSCLIV2.pkg -target /`

    - Run `aws --version` to validate install
    
    **Windows**
    - Open **Windows PowerShell ISE Run as administrator** and run the following commands
    
      `msiexec.exe /i https://awscli.amazonaws.com/AWSCLIV2.msi`
    
    - Run `aws --version` to validate install

2. Once installed, run `aws configure` to configure your user profile

    - Provide the AWS access key and secret access key you previously created and stored in your password manager
    - Hit enter for the rest of the questions to keep the defaults
