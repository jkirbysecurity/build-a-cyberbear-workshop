# 0.2 - Install VS Code

This section walks through installing **Visual Studio Code (VS Code)**

[Download Visual Studio Code](https://code.visualstudio.com/download)

1. Download the installer for your respective system and run the installer with all the defaults

    ![vscode download!](/0-setup-workshop/images/vscode-download.png)


## Get To Know VS Code

VS Code should start up automatically after installing.  If it does not, go ahead and open it.

Explore the following areas to get to know your working environment and install the required extensions for Terraform.

- **File --> Preferences --> Themes --> Color Theme**
    - Play around with the different Color Themes and select what you like best
- **EXPLORER**
    - This is a file explorer.  Similar to the one for your operating system.  This area shows the Project and/or files you are working in.
    - It is recommended to open a new window for different projects.
- **Extensions** 
    - Install `HashiCorp Terraform` & `HCP Terraform`
- **Terminal**
    - If you are on a Windows system, make sure to use **bash**, NOT PowerShell
    - This a built-in terminal that allows you to do and run all your terminal work, actions, and commands from within VS Code.  You do not need to maintain a separate window/environment for your terminal work requiring you to toggle back and forth.
