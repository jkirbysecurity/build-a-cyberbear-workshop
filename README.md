# Build-A-CyberBear Workshop
### Building Ranges in AWS with Terraform

## Overview

In a modern cloud-first world -- cloud developers, engineers, and defenders of all kinds need to be able to build and reliably deliver secure cloud infrastructure with code and at scale.  Organizations are running their infrastructure and applications in the cloud. And, to deliver enterprise-grade cloud infrastructure and services at scale, organizations build using **Infrastructure as Code (IaC)**. 

This is a hands-on workshop designed to teach students the **fundamentals** of building **secure-by-design** infrastructure in AWS using **Terraform (IaC)**. Students will be taken step-by-step through the process of using Terraform to build a small, customizable cloud computing environment in AWS, consisting of a private cloud network and servers. 

These are some of the most valuable multidisciplinary skills necessary to build and secure cloud services. 

Throughout this workshop, students will go on a journey learning the fundamental tools and practices to be successful building the cloud.  By the end of their journey, they will have built customizable cyber ranges that they can reuse to continue their own learning and development, or bring into their organizations as templated examples for their teams to adopt and build off of. 

Build it >>> use it >>> break it >>> tear it down when you are done >>> and then do it all over again – Learn how to build the future, today. 

While this is a fundamentals workshop, it is anything but basic.  You will come out the other side equipped with next-level cloud warrior skills.

Join me!  **Learn to program the cloud** -- securely, reliably, and at scale.


## Learning Objectives

This workshop takes students through the fundamentals of **Infrastructure as Code (IaC)** and **Terraform**, how to build cloud infrastructures (aka ranges) with it, and why it is such an important skill to learn and be comfortable with in security, cloud operations, and development.  Along the way, students will learn about and how to build many of the most commonly used AWS resources and services.

By the end of this workshop, students will be comfortable building small cloud ranges consisting of a variety of resources in **AWS** using **Terraform**, as well as, navigating developer documentation for self-help and continued growth.

### Learn the fundamentals:

Learn to program the cloud so that you can better secure and defend it

- Infrastructure as Code (IaC) w/Terraform
- AWS – Infrastructure (IaaS)
- How to build reusable cyber ranges in the cloud

This is a true **Cyber Ranger** workshop.  And I will be your guide on this most excellent journey. 


### By the end of this Workshop, participants will:

- Understand the fundamentals of using code via **Terraform** to build and deploy cloud infrastructure in AWS
- Understand and be able to build **AWS VPC's, Subnets and routing, Security Groups and EC2 Instances** in code using Terraform
- Have a completed portfolio project that they can store in GitHub or other version control system and share with potential employers and the community showcasing their **Cloud Ranger** skills

These are all foundational skills necessary for a well-balanced cyber ranger.

### Prerequisites:
- Personal AWS Account (free tier recommended)
- Familiarity with simple networks and concepts
    - subnets, servers, firewalls, etc.
- Some familiarity with AWS recommended, but not required
- Comfortable with text editors and command lines (CLI) recommended, but not required
- Ability to install software/tools
- Most importantly --> eagerness to learn, willingness to ask questions, and having fun while doing it!

### Tips & Tricks for Success

- Embrace the struggle and grind.  This is where the deepest & best learning happens.
    –  Remember that learning and growth is a journey, not a destination.  There are no shortcuts.
- Work through the exercises carefully the first time through following the directions step-by-step.  
    - Copy/paste code snippets the first time through to get the feeling of how things work.
    - Then, go back and rebuild a bunch more times tweaking things – pulling all the handles and turning all the knobs.
    - After a few times through, type things out for muscle memory versus the copy & pasting you initially did.
- Write things down / take notes – start a glossary, do additional research/googling as needed
    - What comes easily and why?
    - What are you struggling with?
    - What do you find interesting?
- Seriously, write things down.  Do not type... handwrite.  
    - Research shows that the visceral experience of physical writing imprints on your brain in ways that typing on a computer does not.  
- Read the docs
- Most importantly, have fun!  Building things is fun!
