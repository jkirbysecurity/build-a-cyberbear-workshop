# Section 1: Terraform Fundamentals

### Objectives

The initial section of **Programming the Cloud with Terraform** is intended to get students familiar with the core concepts of Infrastructure as Code and Terraform -- learning the vocabulary, the building blocks, how it all works, and getting familiar with the important documentation.

This is a taster section, we will go more in-depth on each of these topics throughout the workshop and your range building adventure.
