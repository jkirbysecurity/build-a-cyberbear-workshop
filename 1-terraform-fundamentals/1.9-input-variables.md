# 1.9 - Input Variables

Terraform includes a few kinds of blocks for requesting or publishing **named** values. → **Input Variables, Locals, and Outputs**

With respect to **Input Variables**

- These values serve as parameters for a Terraform resource or module so users can customize behavior without editing the source

- Commonly used with modules to define default values

- Gives your module consumer the flexibility to change values at run time
