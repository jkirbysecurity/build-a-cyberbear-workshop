# 1.13 - Terraform State

Terraform automatically stores the current **state** of your infrastructure configurations.

- A state file is created on deployment to codify the configurations of the infrastructure that has been deployed.

- Changes to a configurations file (add, change, delete) are compared against the existing state file, and changes are made to the deployed infrastructure based on the difference between the new configuration and the existing state.

- Terraform State is stored locally by default.

- However, it is best to store state remotely for production and/or shared usage – for example, in an S3 bucket.
