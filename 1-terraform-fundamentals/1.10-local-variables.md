# 1.10 - Local Variables --> "locals"

- AKA “locals” -- exist inside a `locals` code block and curly brackets allowing for multiple local variables to be defined

- Convenient feature for assigning a short name to an expression

- Generic → quick use

- Commonly used with resources in a given configuration file

- For example, you could define a locals block to create a consistent naming convention, identify your primary subnet, and to set aside environmental configuration settings
