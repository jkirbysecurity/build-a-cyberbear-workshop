# 1.2 - Common IaC Tools & Languages

These are some of the most common tools and languages used with Infrastructure as Code.  This is not all inclusive.

- **Infrastructure Provisioning Tools** → Terraform, AWS CloudFormation
    - Provisions infrastructure
- **Configuration Management Tools** → Ansible, Puppet, Chef
    - Manages configurations of software on servers like operating systems and 3rd party software, packages, and applications
- **Common Languages** → Terraform HCL, JSON, YAML 

** This workshop will be focusing on **Terraform**
