# 1.14 - Terraform CLI Basics

The Terraform CLI is how you interact with Terraform and deploy infrastructure.


**Most common commands:**

- `terraform init` – Initiates your configuration.  Pulls down providers, plugins, modules, and other related requirements.  Prepare your working directory for other commands

- `terraform validate` – Checks whether the configuration is valid

- `terraform fmt` – Reformat your configuration in the standard style

- `terraform plan` – Shows changes required by the current configuration → what is your current configuration going to deploy → dry run without making actual changes

- `terraform apply` – Create or update infrastructure

- `terraform destroy` – Destroy previously-created infrastructure → do not forget to destroy when your just playing around and/or testing

- `terraform show` – Show the current state or a saved plan

- `terraform state` – Advanced state management
