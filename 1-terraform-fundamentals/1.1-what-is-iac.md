# 1.1 - What is Infrastructure as Code (IaC)?

Infrastructure as Code (IaC) is the practice and methodology of building, configuring, and managing technology infrastructure using software → i.e., code.

Infrastructure as Code *tools* allow you to manage infrastructure with configuration files rather than through a graphical user interface. Thus allowing you to build, change, and manage your infrastructure in a safe, consistent, and repeatable way by defining resource configurations that you can version control, reuse, and share.

Historically, code is used to create software applications...  Now code and software can be used to create and manage infrastructure using API’s.

**Side note:** API stands for Application Programming Interface.  This is how applications and services communicate and interact with each other.  Modern web sites and applications are built on API's.
