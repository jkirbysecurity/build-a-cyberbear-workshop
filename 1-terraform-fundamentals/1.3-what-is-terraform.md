# 1.3 - What is Terraform?​

Terraform is HashiCorp's Infrastructure as Code tool. It lets you define resources and infrastructure in human-readable, declarative configuration files, and manages your infrastructure lifecycle. 

**Points of note:**
- **HCL - Hashicorp Configuration Language:** Is the declarative language designed to be both human-readable and machine-friendly. It is used to define ***what*** resources you want (e.g., servers, databases, networks) without writing step-by-step scripts for ***how*** to build them.
- **Terraform:** Is the core Infrastructure as Code (IaC) tool. It reads your HCL files, calculates the changes needed, interacts with the cloud provider's APIs, and maintains the state of your infrastructure.

Using Terraform has several advantages over manually managing your infrastructure:

- **Cloud agnostic** – Terraform can manage infrastructure on multiple cloud platforms
- **Human-readable** – Configuration language helps you write infrastructure code quickly
- **Resource tracking** – Terraform State allows you to track resource changes throughout your deployments
- **Modular** – Package code into Modules to reuse common patterns
- **Version control** – Since your infrastructure is code, you can commit your configurations to version control to safely collaborate on infrastructure. Also allows for putting through the Software Development Lifecycle (SDLC) and apply DevSecOps principles, methodologies and testing tools.
