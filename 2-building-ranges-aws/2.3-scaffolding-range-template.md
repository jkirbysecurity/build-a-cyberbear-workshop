## Key sections of the template:

### `terraform.tf` 

The `terraform.tf` file is a commonly used file to specify Terraform configurations and required providers.  For our purposes, we are using the `aws` and `random` providers.

### `main.tf`

#### VARIABLES

Global input variables - with these variables, we can add a description for the variable, a default value, variable type (string, numeric, bool, etc).

#### PROVIDERS

This is where we can further various providers we want to work with in our range.  

#### DATA Sources

Data Sources allow us to search for (lookup) and use information outside of Terraform.  For example with our range, we are going to use data sources to pull in the AWS AMI's information for the EC2 Instances we are going to build.

#### GENERIC RESOURCES

Generic Resources is just a section of the template where you might want to add resources that might be used with/for other resources, but maybe they do not fit nicely into another section or they are being used across several other resources.

#### LOCAL VARIABLES

Local variables, or "locals" as they are referred to are similar to the variables above, however, local variables do not have details, types or defaults.  Local variables are just an assigned value --> *something = something*

#### AWS SSH KEYPAIR

This is the section where we will add the code for generating our ssh keys.

#### NETWORK

Network resources include things like VPC's, subnets, gateways, and route tables

#### SECURITY

Security Group configurations

#### CYBER BEARS

This is the section that we will be using for adding our CyberBears (EC2 Instances), and the details for how we want them built.

#### OUTPUTS

The OUTPUTS section will include details that we want output or returned from deploying the code.  These are things we need to know when it is done building.

### Common Terraform File Configurations

While it is possible to put all of your Terraform code into a single `main.tf` file, it is generally recommended to break down your code/range into a few common files.  

A fairly common default practice is to use the following files.
- `main.tf`
- `terraform.tf`
- `variables.tf`
- `outputs.tf`

For the purposes of this course, we will only be using the `main.tf` and `terraform.tf` files.
